Poster 3 / 3 — Get Started
Setup 2 commands

Get started
in 2 commands

No manual JSON editing. The setup wizard auto-detects every AI CLI you have installed and writes the config for you. Press Enter to skip any prompt — you can fill in values later.

Step 01 — Connect Play Console
Run the setup wizard
npx android-vitals-mcp setup
Prompts for your Google Service Account key path and Android package name, then writes the MCP server config into every detected AI CLI automatically.
● ~/.claude.json
● ~/.gemini/settings.json
● ~/.cursor/mcp.json
● ~/.kiro/settings/mcp.json
Step 02 — Install Skill Playbooks
Install skill playbooks
npx android-vitals-install-skills
Drops 4 guided SKILL.md playbooks into every detected AI CLI's skills directory. Safe to re-run anytime — backs up changed files.
✓ installed new skill written
= unchanged byte-identical, no-op
↻ updated .bak backup created
Then restart your AI CLI and ask:
the skill auto-triggers — no setup command needed
"improve my Android crash rate"
